🦈 blahArch repository

the official package repository for the blahArch Linux distribution and the haj package manager.

installation

to use this repository, append the following configuration to the bottom of your /etc/pacman.conf file:

[blaharch]
SigLevel = Optional TrustAll
Server = https://asitos.github.io/blaharch-repo/$arch

usage

once added, synchronize your databases to access the packages:

sudo pacman -Sy haj
